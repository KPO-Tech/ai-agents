# KPO-Tech · Agents IA

Les projets d'agents IA des vidéos de la chaîne YouTube **KPO-TECH**.
*The AI agent projects from the KPO-TECH YouTube channel, one folder per project.*

**Un dossier = un projet.** Chaque dossier contient son propre `README.md` (ce que fait l'agent, comment le lancer), son code et, quand c'est utile, ses données d'exemple. Dans les vidéos, le lien est toujours le même : cette page. La description de la vidéo indique le dossier à ouvrir.

## Comment utiliser un projet

1. Ouvre le dossier du projet et lis son `README.md`.
2. Suis les instructions d'installation et de lancement qui y sont données.
3. Si le projet appelle un vrai modèle, copie `.env.example` en `.env` et mets **ta propre clé** : les clés ne sont jamais dans ce dépôt.

## Règles du dépôt

- Aucun secret, aucune clé, aucun fichier `.env`.
- Les données d'exemple sont imaginaires ou publiques, et indiquées comme telles.
- Les sorties montrées dans les vidéos viennent d'exécutions réelles ; les captures utiles sont gardées dans le dossier du projet.
